# Codex Theme Switcher 0.2.9-beta.3

## Flexible Codex app discovery

- Automatically finds Codex through the running application, macOS Launch Services, and common installation locations.
- Adds a setting for choosing a renamed, relocated, or externally stored Codex app, plus an option to return to automatic discovery.
- Adds `--codex-app <path>` to the Agent CLI so agents and automation can target a specific Codex installation.
- Keeps status, stop, and clear commands usable even when a previously configured Codex app has been moved.
