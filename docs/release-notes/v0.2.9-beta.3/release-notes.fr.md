# Codex Theme Switcher 0.2.9-beta.3

## Détection flexible de l’app Codex

- Recherche automatiquement Codex parmi les apps en cours d’exécution, via macOS Launch Services et dans les emplacements d’installation courants.
- Ajoute un réglage pour choisir une app Codex renommée, déplacée ou stockée sur un disque externe, avec retour possible à la détection automatique.
- Ajoute `--codex-app <path>` à l’Agent CLI afin que les agents IA et les automatisations puissent cibler une installation précise.
- Les commandes d’état, d’arrêt et de nettoyage restent disponibles même si l’app Codex configurée a été déplacée.
