# Codex Theme Switcher 0.2.9-beta.3

## 柔軟な Codex App の検出

- 起動中の App、macOS Launch Services、一般的なインストール先から Codex を自動検出します。
- 名前を変更した Codex、移動した Codex、外付けディスク上の Codex を選択できる設定と、自動検出へ戻す機能を追加しました。
- Agent CLI に `--codex-app <path>` を追加し、AI agent や自動化から特定の Codex を指定できます。
- 設定済みの Codex を移動した後でも、状態確認、停止、消去コマンドを利用できます。
