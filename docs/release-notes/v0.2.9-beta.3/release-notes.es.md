# Codex Theme Switcher 0.2.9-beta.3

## Detección flexible de la app Codex

- Busca Codex automáticamente entre las apps en ejecución, mediante macOS Launch Services y en las ubicaciones de instalación habituales.
- Añade un ajuste para elegir una app Codex renombrada, trasladada o guardada en un disco externo, con opción para volver a la detección automática.
- Añade `--codex-app <path>` a Agent CLI para que los agentes de IA y las automatizaciones puedan usar una instalación concreta.
- Los comandos de estado, detención y limpieza siguen funcionando aunque la app Codex configurada se haya movido.
