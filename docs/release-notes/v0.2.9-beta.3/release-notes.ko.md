# Codex Theme Switcher 0.2.9-beta.3

## 유연한 Codex App 검색

- 실행 중인 App, macOS Launch Services 및 일반적인 설치 위치에서 Codex를 자동으로 찾습니다.
- 이름이 바뀌었거나 이동되었거나 외장 디스크에 저장된 Codex를 선택하는 설정과 자동 검색으로 되돌리는 기능을 추가했습니다.
- Agent CLI에 `--codex-app <path>`를 추가하여 AI agent와 자동화가 특정 Codex 설치를 지정할 수 있습니다.
- 이전에 설정한 Codex가 이동된 경우에도 상태, 중지 및 초기화 명령을 계속 사용할 수 있습니다.
