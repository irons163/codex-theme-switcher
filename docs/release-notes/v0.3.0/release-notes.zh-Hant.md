# Codex Theme Switcher 0.3.0

## 動態 Voice 虛擬角色與更完整的主題工作室

- 可自訂 ChatGPT／Codex Voice 的獨立背景、圓球人物位置、2×2 或 3×3 嘴型、眨眼、待機動作、脈動同步、縮放、透明度與發光效果。
- 新主題會帶入可直接使用的動態人物預設，匯出與分享主題時也會完整內嵌圖片。
- 嘴型與閉眼圖片會在聲音驅動動畫開始前完成載入及解碼，期間固定顯示閉嘴圖，避免開始說話的第一秒閃爍。
- 可在 App 內直接選擇英文、繁體中文、簡體中文、法文、西班牙文、日文與韓文。
- 可直接重新命名自訂主題並支援復原與重做，設定、版本資訊和更新視窗也能穩定開啟。
