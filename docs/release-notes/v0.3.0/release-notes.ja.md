# Codex Theme Switcher 0.3.0

## アニメーション Voice アバターと、より充実したテーマスタジオ

- ChatGPT／Codex Voice に専用背景、位置調整できるオーブ内ポートレート、2×2／3×3 の口形、まばたき、待機モーション、脈動同期、拡大縮小、不透明度、発光効果を設定できます。
- 新しいテーマにはすぐ使えるアニメーションアバターが入り、書き出しや共有時も画像がテーマ内に保持されます。
- 音声連動アニメーションの開始前に口形と閉眼画像を読み込み・デコードし、準備中は閉じた口を表示することで最初の1秒のちらつきを防ぎます。
- アプリ内で英語、繁体字中国語、簡体字中国語、フランス語、スペイン語、日本語、韓国語を直接選択できます。
- 編集可能なテーマ名を直接変更して取り消し／やり直しができ、設定、バージョン情報、更新画面にも安定してアクセスできます。
