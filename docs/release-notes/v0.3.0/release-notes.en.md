# Codex Theme Switcher 0.3.0

## Animated Voice avatars and a more complete theme studio

- Customize the ChatGPT/Codex Voice experience with separate backgrounds, positioned orb portraits, 2×2 or 3×3 mouth frames, blinking, idle motion, pulse synchronization, scale, opacity, and glow.
- New themes include a ready-to-use animated avatar preset whose images remain embedded when themes are exported and shared.
- Mouth and blink images are loaded and decoded before audio-driven animation starts, keeping the closed-mouth frame visible and preventing the first-second flash.
- Choose the interface language directly in the app from English, Traditional Chinese, Simplified Chinese, French, Spanish, Japanese, and Korean.
- Rename editable themes directly with undo and redo support, while settings, version information, and update dialogs remain reliably accessible.
