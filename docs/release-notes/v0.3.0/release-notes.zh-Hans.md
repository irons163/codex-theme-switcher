# Codex Theme Switcher 0.3.0

## 动态 Voice 虚拟角色与更完整的主题工作室

- 可自定义 ChatGPT／Codex Voice 的独立背景、圆球人物位置、2×2 或 3×3 嘴型、眨眼、待机动作、脉动同步、缩放、透明度与发光效果。
- 新主题会带入可直接使用的动态人物预设，导出与分享主题时也会完整嵌入图片。
- 嘴型与闭眼图片会在声音驱动动画开始前完成加载和解码，期间固定显示闭嘴图，避免开始说话的第一秒闪烁。
- 可在 App 内直接选择英文、繁体中文、简体中文、法文、西班牙文、日文与韩文。
- 可直接重命名自定义主题并支持撤销与重做，设置、版本信息和更新窗口也能稳定打开。
