# Codex Theme Switcher 0.3.0

## 애니메이션 Voice 아바타와 더욱 완성도 높은 테마 스튜디오

- ChatGPT/Codex Voice에 전용 배경, 위치를 조절할 수 있는 오브 인물 이미지, 2×2 또는 3×3 입 모양, 눈 깜빡임, 대기 동작, 맥동 동기화, 크기, 불투명도 및 발광 효과를 설정할 수 있습니다.
- 새 테마에는 바로 사용할 수 있는 애니메이션 아바타 프리셋이 포함되며, 테마를 내보내거나 공유할 때도 이미지가 그대로 포함됩니다.
- 음성 기반 애니메이션을 시작하기 전에 입 모양과 눈 감은 이미지를 미리 불러와 디코딩하고, 준비 중에는 닫힌 입 이미지를 유지하여 첫 1초의 깜빡임을 방지합니다.
- 앱에서 영어, 중국어 번체, 중국어 간체, 프랑스어, 스페인어, 일본어 및 한국어를 직접 선택할 수 있습니다.
- 편집 가능한 테마 이름을 직접 변경하고 실행 취소와 다시 실행을 사용할 수 있으며, 설정, 버전 정보 및 업데이트 창에도 안정적으로 접근할 수 있습니다.
