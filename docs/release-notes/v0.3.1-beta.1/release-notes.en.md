# Codex Theme Switcher 0.3.1-beta.1

## Installed-app launch hotfix

- Fixes a crash that prevented the signed 0.3.0 app from opening after installation.
- Packages the default Animated Voice Avatar mouth and blink images in release installers.
- Adds regression coverage for resolving Voice assets from the installed app bundle.
- Beta testers upgrading from 0.3.0 must install this release manually because 0.3.0 cannot launch its updater.
