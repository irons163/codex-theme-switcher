# Codex Theme Switcher 0.3.0-beta.3

## Dialogues de mise à jour stables

- Affiche Mise à jour, Nouveautés et À propos dans des modales intégrées à la fenêtre.
- Empêche un clic dans le dialogue de fermer toute la fenêtre de la barre des menus.
- Bloque les interactions en arrière-plan pendant l’affichage d’une modale.
- Permet de fermer la modale avec Échap.
