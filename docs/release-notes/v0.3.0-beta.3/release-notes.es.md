# Codex Theme Switcher 0.3.0-beta.3

## Diálogos de actualización estables

- Muestra Actualización, Novedades y Acerca de como modales dentro de la ventana.
- Evita que un clic en el diálogo cierre toda la ventana de la barra de menús.
- Bloquea la interacción con el fondo mientras hay un modal abierto.
- Permite cerrar el modal con Escape.
