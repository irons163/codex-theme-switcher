# Codex Theme Switcher 0.2.8

## Primera versión pública

- Estudio de temas nativo para macOS en la barra de menús, con tres plantillas integradas: Midnight, Paper y High Contrast.
- Control completo de colores, tipografía, diseño, componentes, selectores CSS y CSS sin procesar.
- Image Skin admite fondos Light y Dark independientes, Fit / Fill, fondo de pantalla para toda la ventana o sin la barra lateral, cristal por sección y un panel de contenido central.
- La importación y exportación en un único archivo `.codextheme` conserva las imágenes, fuentes y demás recursos integrados.
- Interfaz localizada en inglés, chino tradicional, chino simplificado, francés, español, japonés y coreano.
- Actualizaciones firmadas con Sparkle mediante canales Stable y Beta, notas de la versión localizadas e instaladores para Apple Silicon o Intel.
- El CLI `codex-theme`, diseñado JSON-first, permite a los agentes de IA consultar el esquema, validar y compilar temas, y generar vistas previas PNG sin ventanas Light/Dark × Home/Chat.
- «Restaurar los estilos originales de Codex» permite recuperarse con seguridad incluso si un tema personalizado está dañado.
