# Codex Theme Switcher 0.2.8

## 初次公开版本

- 原生 macOS menu bar 主题工作室，内置 Midnight、Paper 与 High Contrast 三个模板。
- 完整控制色彩、字体、版面、组件、CSS selector 与 raw CSS。
- Image Skin 支持独立的 Light／Dark 背景、Fit / Fill、全窗口或避开左侧栏的 wallpaper 范围、分区 glass 与中央内容面板。
- 单文件 `.codextheme` 导入／导出会保留嵌入图片、字体及其他素材，便于携带与分享。
- 界面支持英语、繁体中文、简体中文、法语、西班牙语、日语与韩语。
- 已签名的 Sparkle 更新支持 Stable／Beta 频道、七种语言的版本说明，以及 Apple Silicon／Intel 对应安装程序。
- JSON-first `codex-theme` CLI 让 AI agent 获取 schema、验证与编译主题，并生成无窗口的 Light／Dark × Home／Chat PNG 预览。
- 即使自定义主题损坏，仍可使用“恢复 Codex 原始样式”安全还原。
