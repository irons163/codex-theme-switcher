# Codex Theme Switcher 0.2.8

## 첫 공개 릴리스

- macOS menu bar에서 실행되는 네이티브 테마 스튜디오로, Midnight, Paper, High Contrast 세 가지 내장 템플릿을 제공합니다.
- 색상, 글꼴, 레이아웃, 컴포넌트, CSS selector, raw CSS를 세밀하게 설정할 수 있습니다.
- Image Skin은 Light／Dark 개별 배경, Fit / Fill, 전체 창 또는 왼쪽 사이드바를 제외하는 wallpaper 범위, 영역별 glass, 중앙 콘텐츠 패널을 지원합니다.
- 단일 `.codextheme` 파일 가져오기／내보내기에 포함된 이미지, 글꼴 및 기타 asset이 그대로 유지됩니다.
- 영어, 번체 중국어, 간체 중국어, 프랑스어, 스페인어, 일본어, 한국어 UI를 제공합니다.
- 서명된 Sparkle 업데이트는 Stable／Beta 채널, 현지화된 릴리스 노트, Apple Silicon／Intel별 설치 파일을 지원합니다.
- JSON-first `codex-theme` CLI를 통해 AI agent가 schema를 확인하고 테마를 검증 및 컴파일하며 Light／Dark × Home／Chat의 창 없는 PNG 미리보기를 생성할 수 있습니다.
- 사용자 지정 테마가 손상되어도 “Codex 원래 스타일 복원”을 사용해 안전하게 복구할 수 있습니다.
