# Codex Theme Switcher 0.2.8

## Initial public release

- Native macOS menu bar theme studio with three built-in templates: Midnight, Paper, and High Contrast.
- Complete theme controls for colors, typography, layout, components, CSS selectors, and raw CSS.
- Image Skin supports separate Light and Dark backgrounds, Fit / Fill, whole-window or sidebar-free wallpaper scope, per-section glass, and a central content panel.
- Single-file `.codextheme` import and export keeps embedded images, fonts, and other assets portable.
- Localized interface in English, Traditional Chinese, Simplified Chinese, French, Spanish, Japanese, and Korean.
- Signed Sparkle updates with Stable and Beta channels, localized release notes, and installers matched to Apple Silicon or Intel.
- The JSON-first `codex-theme` CLI lets AI agents inspect the schema, validate and compile themes, and render headless Light/Dark × Home/Chat PNG previews.
- “Restore Original Codex Styles” provides a safe recovery path even when a custom theme is broken.
