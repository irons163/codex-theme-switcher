# Codex Theme Switcher 0.2.8

## 初回公開リリース

- macOS menu bar で動作するネイティブなテーマスタジオ。Midnight、Paper、High Contrast の 3 つの組み込みテンプレートを収録。
- 色、フォント、レイアウト、コンポーネント、CSS selector、raw CSS を詳細に設定可能。
- Image Skin は Light／Dark 個別の背景、Fit / Fill、ウィンドウ全体または左サイドバーを除外する wallpaper 範囲、領域別 glass、中央コンテンツパネルに対応。
- 単一ファイルの `.codextheme` インポート／エクスポートに、埋め込み画像、フォント、その他のアセットを保持。
- 英語、繁体字中国語、簡体字中国語、フランス語、スペイン語、日本語、韓国語の UI を収録。
- 署名済み Sparkle アップデートで Stable／Beta チャンネル、ローカライズされたリリースノート、Apple Silicon／Intel 別インストーラーに対応。
- JSON-first の `codex-theme` CLI により、AI agent は schema の参照、テーマの検証とコンパイル、Light／Dark × Home／Chat のヘッドレス PNG プレビュー生成が可能。
- カスタムテーマが壊れた場合も、「Codex の元のスタイルに復元」から安全に復旧可能。
