# Codex Theme Switcher 0.2.8

## 初次公開版本

- 原生 macOS menu bar 主題工作室，內建 Midnight、Paper 與 High Contrast 三個模板。
- 完整控制色彩、字體、版面、元件、CSS selector 與 raw CSS。
- Image Skin 支援獨立的 Light／Dark 背景、Fit / Fill、全視窗或避開左側欄的 wallpaper 範圍、分區 glass 與中央內容面板。
- 單檔 `.codextheme` 導入／導出會保留內嵌圖片、字型及其他素材，方便攜帶與分享。
- 介面支援英文、繁體中文、簡體中文、法文、西班牙文、日文與韓文。
- 已簽署的 Sparkle 更新支援 Stable／Beta 頻道、七語版本說明，以及 Apple Silicon／Intel 對應安裝程式。
- JSON-first `codex-theme` CLI 讓 AI agent 取得 schema、驗證與編譯主題，並產生無視窗的 Light／Dark × Home／Chat PNG 預覽。
- 即使自訂主題損壞，仍可用「恢復 Codex 原始樣式」安全復原。
