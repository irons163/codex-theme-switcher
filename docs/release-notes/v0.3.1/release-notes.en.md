# Codex Theme Switcher 0.3.1

## Installed-app launch hotfix

- Fixes the crash that prevented the signed 0.3.0 app from opening after installation.
- Packages the default Animated Voice Avatar mouth and blink images in both release installers.
- Adds regression coverage for resolving Voice assets from the installed app bundle.
- Validated through the 0.3.1 beta on Apple Silicon and Intel.
- Users upgrading from 0.3.0 must install this release manually because 0.3.0 cannot launch its updater.
