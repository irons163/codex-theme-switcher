# Codex Theme Switcher 0.3.4

## Codex の外観と音声の修正

- 最近の Codex 更新後に会話欄と入力欄の背後で背景画像が見えなくなる問題を修正し、不要な不透明背景と端のグラデーションを取り除きました。
- カスタムテーマのサイドバー文字、プロジェクト作成欄、塗りつぶしボタンのコントラストを修正し、アプリで明示的に選択したライト・ダーク表示に対応しました。
- 新しい音声画面でフレーム付き Live2D キャラクターを表示し、ネイティブの操作ボタンをスマートフォンの下に配置します。
- スマートフォン、キャラクター、操作ボタンを一度の滑らかなドラッグで一緒に移動でき、アプリのセッション中は位置を記憶します。音声を閉じるとドラッグ領域を削除します。
