# Codex Theme Switcher 0.3.4

## Codex 화면 및 음성 수정

- 최근 Codex 업데이트 이후 대화와 입력 영역 뒤의 배경 이미지가 보이지 않는 문제를 수정하고 불필요한 불투명 표면과 가장자리 그라데이션을 제거했습니다.
- 사용자 지정 테마의 사이드바 글자, 프로젝트 생성 필드, 단색 버튼 대비를 수정하고 앱에서 명시적으로 선택한 밝은 모드와 어두운 모드를 지원합니다.
- 새 음성 화면에서 프레임 안의 Live2D 캐릭터가 표시되도록 수정하고 기본 조작 버튼을 휴대폰 아래에 배치합니다.
- 휴대폰, 캐릭터, 조작 버튼을 한 번의 부드러운 드래그로 함께 이동할 수 있으며 앱 세션 동안 위치를 기억합니다. 음성을 닫으면 드래그 영역을 제거합니다.
