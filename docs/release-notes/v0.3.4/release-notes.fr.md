# Codex Theme Switcher 0.3.4

## Corrections de l’apparence et du mode vocal de Codex

- Rétablit la visibilité du fond derrière la conversation et la zone de saisie après les dernières mises à jour de Codex, en supprimant les surfaces opaques et les dégradés de bord indésirables.
- Corrige le contraste du texte latéral, des champs de création de projet et des boutons pleins dans les thèmes personnalisés, y compris les apparences claire et sombre définies dans l’application.
- Maintient le personnage Live2D dans son cadre visible dans la nouvelle interface vocale et place les commandes natives sous le téléphone.
- Permet de déplacer ensemble le téléphone, le personnage et les commandes d’un geste fluide, mémorise leur position pendant la session et supprime la zone de déplacement à la fermeture du mode vocal.
