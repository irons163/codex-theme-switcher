# Codex Theme Switcher 0.3.0-beta.5

## Direct theme renaming

- Rename editable themes by double-clicking them or using the context menu.
- Edit the selected theme name directly from the preview heading.
- Keeps renames in undo and redo history and updates the theme library immediately.
- Rejects blank names, trims surrounding whitespace, and localizes the controls in all seven languages.
- Built-in themes remain read-only until you make an editable copy.
