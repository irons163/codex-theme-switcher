# Codex Theme Switcher 0.3.0-beta.5

## Cambio directo del nombre del tema

- Cambia el nombre de un tema editable con doble clic o desde el menú contextual.
- Edita directamente el nombre del tema seleccionado en el encabezado de la vista previa.
- Los cambios de nombre se incluyen en el historial de deshacer y rehacer y actualizan la biblioteca de inmediato.
- Se rechazan los nombres vacíos, se eliminan los espacios sobrantes y los controles están traducidos a los siete idiomas.
- Los temas integrados siguen siendo de solo lectura hasta que crees una copia editable.
