# Codex Theme Switcher 0.3.0-beta.5

## Renommage direct des thèmes

- Renommez un thème modifiable par double-clic ou depuis le menu contextuel.
- Modifiez directement le nom du thème sélectionné dans l’en-tête de l’aperçu.
- Les renommages sont intégrés à l’historique d’annulation et de rétablissement, avec mise à jour immédiate de la bibliothèque.
- Les noms vides sont refusés, les espaces superflus sont supprimés et les commandes sont traduites dans les sept langues.
- Les thèmes intégrés restent en lecture seule jusqu’à la création d’une copie modifiable.
