# Codex Theme Switcher 0.2.9

## Conexiones con Codex más fiables

- Selecciona y recuerda automáticamente un port bridge local disponible cuando el predeterminado está ocupado.
- Busca Codex entre las apps en ejecución, mediante macOS Launch Services y en las ubicaciones de instalación habituales.
- Añade un ajuste para elegir una app Codex renombrada, trasladada o guardada en un disco externo, con opción para volver a la detección automática.
- Añade `--codex-app <path>` a Agent CLI para que los agentes de IA y las automatizaciones puedan usar una instalación concreta.
- Incluye instaladores firmados y notarizados por Apple para Mac con Apple Silicon e Intel.
