# Codex Theme Switcher 0.2.9

## More reliable Codex connections

- Automatically selects and remembers an available local bridge port when the default port is occupied.
- Finds Codex through running apps, macOS Launch Services, and common installation locations.
- Adds a setting for choosing a renamed, relocated, or externally stored Codex app, with an option to return to automatic discovery.
- Adds `--codex-app <path>` to the Agent CLI so agents and automation can target a specific Codex installation.
- Includes signed and Apple-notarized installers for Apple Silicon and Intel Macs.
