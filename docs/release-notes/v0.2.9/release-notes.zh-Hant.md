# Codex Theme Switcher 0.2.9

## 更可靠的 Codex 連線

- 預設 bridge port 被占用時，會自動選擇並記住可用的本機 port。
- 會從執行中的 App、macOS Launch Services 與常見安裝位置自動尋找 Codex。
- 新增 Codex App 位置設定，可選擇已改名、搬移或存放於外接磁碟的 Codex，也可恢復自動偵測。
- Agent CLI 新增 `--codex-app <path>`，讓 AI agent 與自動化流程能指定 Codex 安裝位置。
- 提供 Apple Silicon 與 Intel Mac 安裝檔，均已完成簽章與 Apple 公證。
