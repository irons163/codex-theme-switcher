# Codex Theme Switcher 0.2.9

## より安定した Codex 接続

- 既定の bridge port が使用中の場合、利用可能なローカル port を自動で選択して保存します。
- 起動中の App、macOS Launch Services、一般的なインストール先から Codex を自動検出します。
- 名前を変更した Codex、移動した Codex、外付けディスク上の Codex を選択でき、自動検出にも戻せます。
- Agent CLI に `--codex-app <path>` を追加し、AI agent や自動化から特定の Codex を指定できます。
- Apple Silicon／Intel Mac 用の署名済み・Apple 公証済みインストーラーを提供します。
