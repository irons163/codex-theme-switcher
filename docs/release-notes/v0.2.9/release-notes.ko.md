# Codex Theme Switcher 0.2.9

## 더욱 안정적인 Codex 연결

- 기본 bridge port가 사용 중이면 사용 가능한 로컬 port를 자동으로 선택하고 기억합니다.
- 실행 중인 App, macOS Launch Services 및 일반적인 설치 위치에서 Codex를 자동으로 찾습니다.
- 이름이 바뀌었거나 이동되었거나 외장 디스크에 저장된 Codex를 선택할 수 있으며 자동 검색으로 되돌릴 수도 있습니다.
- Agent CLI에 `--codex-app <path>`를 추가하여 AI agent와 자동화가 특정 Codex 설치를 지정할 수 있습니다.
- Apple Silicon 및 Intel Mac용 설치 파일은 서명과 Apple 공증을 완료했습니다.
