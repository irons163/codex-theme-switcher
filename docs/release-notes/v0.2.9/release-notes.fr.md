# Codex Theme Switcher 0.2.9

## Connexions Codex plus fiables

- Sélectionne et mémorise automatiquement un port bridge local disponible lorsque le port par défaut est occupé.
- Recherche Codex parmi les apps en cours d’exécution, via macOS Launch Services et dans les emplacements d’installation courants.
- Ajoute un réglage pour choisir une app Codex renommée, déplacée ou stockée sur un disque externe, avec retour possible à la détection automatique.
- Ajoute `--codex-app <path>` à l’Agent CLI afin que les agents IA et les automatisations puissent cibler une installation précise.
- Inclut des installateurs signés et notariés par Apple pour les Mac Apple Silicon et Intel.
