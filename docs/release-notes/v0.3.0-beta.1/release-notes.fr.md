## Choisissez la langue de l’interface

- Ajoute un menu Langue de l’interface dans Réglages, avec le mode Automatique et sept langues au choix.
- Met immédiatement à jour tout le studio de la barre des menus sans redémarrer l’app.
- Mémorise la langue sélectionnée pour les prochains lancements.
- Le mode Automatique continue de suivre la langue préférée de macOS et utilise l’anglais lorsqu’elle n’est pas prise en charge.
