# Codex Theme Switcher 0.2.9-beta.1

## 첫 Beta 채널 검증 버전

- 최초 정식 버전 0.2.8을 기반으로 한 첫 공개 Beta 빌드입니다.
- 서명된 Sparkle appcast를 통한 전체 Beta 업데이트 흐름을 검증합니다.
- Apple Silicon 및 Intel용 설치 프로그램을 각각 제공하며, 모두 Developer ID로 서명되고 Apple 공증을 완료했습니다.
- 0.2.8과 비교해 의도적인 기능 변경은 없습니다. 설치, 업데이트 확인 및 Beta 채널 동작에 대한 피드백을 부탁드립니다.
